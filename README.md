## 🧠 Sobre o projeto

Este projeto foi desenvolvido durante um **bootcamp realizado na plataforma DIO**, seguindo as aulas, desafios e metodologias propostas ao longo do curso.

A aplicação consiste em um **jogo interativo para navegador**, criado com o objetivo de colocar em prática conceitos fundamentais do desenvolvimento web. O projeto acompanha a proposta comum dos bootcamps, que priorizam o aprendizado através da construção de aplicações reais e funcionais.

O desenvolvimento foi feito utilizando:
- **HTML**
- **CSS**
- **JavaScript**

Durante a construção do projeto, foram aplicados conceitos como:
- lógica de programação  
- manipulação do DOM  
- eventos e interações com o usuário  
- controle de estados do jogo  

## 🎮 Funcionalidade

O jogo apresenta uma mecânica simples e interativa, onde o usuário pode realizar ações diretamente na tela, seguindo regras definidas pela lógica em JavaScript. ## 🎯 Objetivo

O principal objetivo deste projeto foi **aplicar na prática os conhecimentos adquiridos durante o bootcamp da DIO**, desenvolvendo uma aplicação funcional enquanto acompanhava as aulas.

Além disso, o projeto contribui para:
- reforçar o aprendizado prático  
- desenvolver autonomia na resolução de problemas  
- construir portfólio com projetos reais  

## 💡 Considerações

Este projeto representa minha evolução ao longo do bootcamp, demonstrando minha capacidade de aplicar conceitos de desenvolvimento web na prática, seguindo as metodologias da DIO, que são baseadas em aprendizado ativo e construção de projetos.
